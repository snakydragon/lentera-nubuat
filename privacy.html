Privacy Policy

Last updated: 5 November 2026

Lentera Nubuat Uploader is a private tool used only by the owner of the Lentera Nubuat YouTube channel.

What it accesses

With the owner's permission, it uses the YouTube Data API to upload videos, set thumbnails and manage playlists on the owner's own channel, and to read that channel's public statistics.

What it collects

It collects no data from viewers or any other person. It does not sell, share or transfer any data to third parties.

Storage

The sign-in token is stored only on the owner's own computer and is used only to act on the owner's channel. Access can be revoked at any time at myaccount.google.com/permissions.

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
